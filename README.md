## Getting Started

You can run the website locally without installing any packages or frameworks.

### Prerequisites

- A web browser
- Git (optional, for cloning the repository)
- A code editor such as Visual Studio Code (recommended)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/balramrawatx/balramrawatx.github.io.git
   ```

2. Navigate to the project directory:

   ```bash
   cd balramrawatx.github.io
   ```

3. Open `index.html` in your browser.

   Alternatively, use the Live Server extension in Visual Studio Code for convenient local development.

## Deployment

This website is designed to be hosted as a GitHub Pages user site.

1. Open the repository on GitHub.
2. Navigate to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the `main` branch and the `/ (root)` folder.
5. Click **Save** and wait for deployment to complete.

Your portfolio will be available at:

**[https://balramrawatx.github.io/](https://balramrawatx.github.io/)**

Future changes pushed to the configured branch will be published automatically by GitHub Pages.

## Customization

The website can be maintained using the existing project files:

- Edit `index.html` to update content, education, projects, and social links.
- Edit `style.css` to customize colours, spacing, layouts, and responsive behaviour.
- Edit `script.js` to modify navigation and interactive features.
- Add your CV as `assets/cv.pdf` if you want to provide a downloadable or viewable résumé.
- Replace project placeholders with real repository links as projects are completed.

Keep the skills, achievements, and project descriptions accurate and up to date.
